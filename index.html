A JavaScript engine on Rule 110

A program on this page is a single print. The engine writes that program as ten cells. Each following row is cellular automaton Rule 110. After three rows, two of the cells are the number print shows.

The language

Every program has this shape. a and b are the bits 0 and 1.

print(0)
print(1)
print(! a)
print(a && b)
print(a || b)
print(a + b)

Addition is one bit wide. 1 + 1 carries, so it prints 2. && and || are the usual JavaScript booleans, with 0 false and 1 true.

The rule

A cell and its two neighbors decide the cell below it. The eight cases are Rule 110. Read the bottom row as a binary number and you get 110.

Left, cell, right, and the cell in the next row

The same table is one formula. Each variable is 0 or 1.

next = min(1, (1 − left) × (center + right) + left × |center − right|)

Two rows, worked by hand:

  • Left 1, center 1, right 1. min(1, (1 − 1) × (1 + 1) + 1 × |1 − 1|) = 0.
  • Left 0, center 0, right 1. min(1, (1 − 0) × (0 + 1) + 0 × |0 − 1|) = 1.

Cells past the ends of the row are empty, so the missing neighbor is 0.

How a program is written

Columns are numbered from 1 on the left. The printed number is read on the third step: column 2 is the twos place, column 4 is the ones place.

printed = 2 × (column 2) + (column 4)

print(0)
Ten empty cells. 0000000000
print(1)
One living cell in column 6. 0000010000
print(! a)
a is written in column 3. Column 6 is living. 00a0010000. When a is 0, this is the same row as print(1).
print(a && b)
1 a 0 1 b 0 1 0 0 0. a is column 2. b is column 5.
print(a || b)
a is column 6. b is column 7. Every other cell is empty. 00000ab000.
print(a + b)
1 a b 1 0 0 1 0 0 0. a is column 2. b is column 3. On the third step, column 2 holds the carry and column 4 holds the sum bit.
